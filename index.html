Your data and backups

Saved in this browser

Groove patterns save automatically. Save patches and loops to keep them in this browser; unsaved patch changes and the current loop are not backed up automatically. Patch audio and some settings are stored here too.

Keep a backup: clearing site data, browser storage eviction, or using private browsing can remove saved data. Data is separate for each browser profile and website address.

Import and export files

Use Import / Export above to download a ZIP of one section or everything, and to import a backup. Imports merge saved items and ask how to handle differing matches.

Individual patches, audio, patterns and loops can also be exported. MIDI exports omit app-specific data.

Google Drive backups

Backups are stored in a visible refaceCS folder in your Google Drive. They can contain patches, loops, patterns and audio. Google Drive storage and account access are your responsibility; sync and deletion mistakes can affect other devices. Browser preferences are not included.

Use the same Google OAuth client ID and account on each device. Google may require you to reconnect after a reload or token expiry. Automatic sync is not yet available.

How to set up Google Drive access
  1. Open Google Cloud Console and create or select a project. Enable the Google Drive API for that project.
  2. In Google Auth Platform, configure the consent screen. Under Data Access, add the https://www.googleapis.com/auth/drive.file scope.
  3. If the app is in Testing mode, open Audience and add your Google account under Test users. Otherwise Google may block access.
  4. Under Clients, create an OAuth client ID of type Web application. Add this app's current origin as an Authorized JavaScript origin: . Add each other origin you use, including its port. Redirect URIs are not needed for this app.
  5. Copy the client ID into the field below, click Connect Google Drive, and approve access using the same account on each device. Do not enter or share the client secret.

Google settings can take time to take effect. For more details, see Google's setup guide.
Groove studio 808-inspired drum machine

One bar per pattern. Click: 5, 4, 3, 2, 1, 2, 3, 4, 5... Right-click or Delete clears a step. Patterns and sound settings save automatically in this browser. MIDI channel 10 triggers the internal drums.

Align a short reface sound against the drums by ear. Negative offset sends looper MIDI earlier; positive sends it later. Use headphones or wired audio for tighter timing. Web Audio does not provide direct ASIO access.

Audio uses the system default until another output is selected.
