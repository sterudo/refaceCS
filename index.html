Device settings

Values are unknown until read. Changes are sent only when you apply them. SysEx permission and a connected reface input and output are required.

Master transpose and tempo are controlled on the main synth panel and read automatically when the synth connects.

Changing MIDI channels, MIDI Control, Local Control or speaker output can interrupt communication or sound. A specific receive channel routes outgoing notes and controls to that channel; All preserves forwarded and loop channels.

Hardware key combinations and factory reset

With the synth off, hold the indicated physical key while powering on. Repeat a toggle procedure to change it back:

  • C2: disable Auto Power-Off.
  • D2: toggle built-in speaker output.
  • E2: toggle MIDI Control.
  • F2: toggle Local Control.
  • A2: toggle MIDI transmit between channel 1 and Off.
  • B2: toggle pitch-bend inversion between +12 and −12 semitones.
  • C♯2: show the current keyboard settings on the synth's LEDs.

Turn the instrument off, hold the appropriate physical key, then turn it on. The keyboard settings diagram in the owner's manual, page 41 identifies the exact keys for speaker output, MIDI Control, Local Control, transmit channel, pitch-bend inversion, Auto Power-Off and setting confirmation. The synth's LEDs indicate the result; see page 44 for the confirmation display.

Firmware 1.30 also provides advanced keyboard settings, including separate transmit and receive channel selection. Hold the A-major chord shown in Yamaha's advanced-settings guidance while powering on, then follow the supplementary manual's key diagrams for the desired setting.

Disabling Auto Power-Off using the keyboard requires a factory reset to re-enable it using that method. SysEx behavior requires hardware verification.

Factory reset erases the hardware loop phrase and restores settings. To reset, hold the rightmost physical key while powering on, and release it after the lights stop flashing. See the factory reset instructions. Reset in this dialog is not a factory reset.

    Backups are stored in a visible refaceCS folder in your Google Drive. They contain patches, loops, patterns, saved SuperKnob presets and audio.     Use the same Google OAuth client ID and account on each device. Google may require you to reconnect after a reload or token expiry. Automatic sync is not yet available.

    How to set up Google Drive access
    1. Open Google Cloud Console and create or select a project. Enable the Google Drive API for that project.
    2. In Google Auth Platform, configure the consent screen. Under Data Access, add the https://www.googleapis.com/auth/drive.file scope.
    3. If the app is in Testing mode, open Audience and add your Google account under Test users. Otherwise Google may block access.
    4. Under Clients, create an OAuth client ID of type Web application. Add this app's current origin as an Authorized JavaScript origin: . Add each other origin you use, including its port. Redirect URIs are not needed for this app.
    5. Copy the client ID into the field below, click Connect Google Drive, and approve access using the same account on each device. Do not enter or share the client secret.

    Google settings can take time to take effect. For more details, see Google's setup guide.
    Groove studio 808-inspired drum machine

    Patterns have 1–16 bars. Click: 5, 4, 3, 2, 1, 2, 3, 4, 5... Right-click or Delete clears a step. Patterns and sound settings save automatically in this browser. Controller MIDI channel 10 triggers drums using the selected output.

    Align a short reface sound against the drums by ear. Negative offset sends looper MIDI earlier; positive sends it later. Internal + MIDI also applies this offset to external drums. Use headphones or wired audio for tighter timing. Web Audio does not provide direct ASIO access.

    Groove MIDI settings

    External MIDI uses its own output and channel. Internal Tune, Decay and Tone controls do not change the external sound.

    CS2x kit selection sets channel 10; Performance selection sets channel 1. Lane Level scales external velocity. Reverb sends CC91 to the selected external channel.

    Standalone software: create a virtual MIDI port (for example loopMIDI on Windows), select it here and as the software synth's MIDI input, then match channels and choose a drum sound in that synth.

    Selecting a preset or choosing Apply sends bank and program changes; custom values are sent only with Apply. The CS2x must already be in the appropriate mode; changing a Performance replaces its current sound. No sound is reapplied on reconnect.

    Lane MIDI notes

    Mappings are global; CS2x Performances remember their own mappings. Notes range from 0 to 127.

    Calibrate MIDI offset

    Listen to the steady 100 BPM kick and play notes on the selected reface MIDI input. Only the delay from the latest kick to the latest received Note On is kept.

    This includes your playing timing and MIDI input delay; it is not an audio-latency measurement. Done applies the measured delay positively, sending looper MIDI later.
